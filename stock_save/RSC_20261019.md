## 企業概要
アール・エス・シー（RSC）は、警備事業・ビルメンテナンス・人材サービス・一般建設・マンション管理を展開する総合施設管理企業。ソフトバンクロボティクス（ソフトバンクG傘下）と2025年11月に資本業務提携を締結し、AI警備ソリューション分野で合弁会社「AI Remote Security」を設立。「SBX AI警備」の導入と自律走行型AI警備ロボット「SBX Security Robot S1」（2026年秋から提供予定）の展開により、従来型警備からAI警備DXへの転換を図っている。2027年8月期は営業利益前期比+89.0%増の業績予想を発表済み。

### キーワード別 業界トレンド

#### [AI警備ロボット / 自律走行警備]
ソフトバンクロボティクスは「SBX Security Robot S1」を月額4.98万円〜で提供。警備業界は人手不足・高齢化が深刻で、ロボットが巡回・監視・異常検知を担うケースが商業施設・空港・データセンターなどで急増中。日本の警備ロボット市場は2025年の約10億ドルから2034年に約30億ドルへ拡大（CAGR 13.04%）と予測されている。

#### [ソフトバンクG / アライドユニバーサル買収]
Bloomberg報道によると、ソフトバンクGがアライド・ユニバーサル（世界最大級の警備会社、18万人以上の社員）を約180億ドルで買収検討中。アリードはデータセンター警備事業を持ち、AI・ロボットの警備への統合を進めている。買収実現で、ソフトバンクのAI警備事業が大幅に強化される見込み。

#### [セキュリティDX / 遠隔監視]
「SBX AI警備」は監視カメラとAI解析を組み合わせた遠隔監視ソリューション。2026年3月にAI Remote SecurityがRSCを引受先として増資を実施し合弁化。遠隔警備サービスを2026年中に本格提供予定。業界標準化が進めば警備業界のDX転換が加速する。

#### [警備業界人手不足・構造転換]
警備業界ではベテラン警備員の退職によるノウハウ喪失と人手不足が深刻化。AIと自律走行ロボットによる代替が進む一方、ロボット導入コスト・法規制・社会受容性が課題として残る。

#### [ビルメンテナンスDX]
マンション管理・ビルメンテナンス領域でもAIによる設備点検・予知保全・BIMs（ビル管理システム）のDX化が進行中。警備・メンテナンスをワンストップで提供する総合施設管理企業の付加価値が向上している。
